> `docs/VERIFY-0.2.1-alpha.1-v1.1.0.md`；本文只记这次的改动、复验与**仍然未验证**的东西。

## 1. 为什么要发这一版：一个只有真机能撞出来的界面缺陷

用户原话：「点击关闭实例网页就不动了，背后实例被立即杀掉」。功能其实是对的（实例干净退出了、启动它的作业收到退出码 0），但**界面没有给出任何看得见的反馈**——那一幕根本截不到。

根因（读代码确认，不是猜）：

- 客户端 `renderShutdownConfirm()` 只区分 `shutdown-confirming` / `shutdown-requested` / `shutdown-failed`；
  而 `closing` 与 `closed` 也在 `SHUTDOWN_PHASES` 里，于是落进最后一个分支；
- `submitting = (phase === 'shutdown-requested')` ⇒ 在 `closing` 里为**假** ⇒ **弹窗退回普通确认框的样子**：
  勾选框在、`confirmLabel` 变回可点的「关闭 DSH」、取消也在（态机虽会拒绝这些事件，按钮看着却是活的）；
- 真正写着「正在关闭」的文案只在**设置页那一行**与 `shell.overlay` 里的**横幅**里，而横幅层级（20）低于
  设置面板（1000）、设置页那一行又被 portal 到 body 的模态盖住；
- 300 ms 后进程退出 ⇒ 死页面上立着一个「看着能点、其实无效」的弹窗 = 用户看到的「网页就不动了」。

## 2. 两处修复

| 修的是什么 | 怎么修 |
| --- | --- |
| **宿主**：退出延迟只够「响应发出去」，不够「人看见」 | `SHUTDOWN_EXIT_DELAY_MS` 300 → **1000 ms**。这一秒买的是可见反馈：202 发出去只要 12 ms（实测），但浏览器还要接收、解析、重渲染，而进程随即消失 |
| **客户端**：唯一可靠的表面不说话 | `shutdown-requested` / `closing` / `closed` 改用**信息型模态**（原生 `Modal`、`headless: true`、portal 到 body）+ 复用阶段文案；**一个可点控件都没有**（勾选框、取消、确认全去掉）。`closed` 只留一个「知道了」收掉模态（阶段仍是 `closed`，横幅与设置页那一行继续说明——收掉不丢信息）。原生 `Modal` 拿不到时退回自带覆盖层 |

## 3. 真机复验 ✅（用户完成）

在一个一次性实例（自己起的、跑的就是这一版代码）上，用户按「设置 → 热重启 → 关闭 DSH → 勾选 → 确认」操作：

- **弹窗变成了信息型**（用户截图确认）：标题「**DSH 正在关闭…**」，正文「进程马上就要退出，这个页面会失去连接，之后不会再收到它的状态。」——**没有勾选框、没有取消、没有任何看起来能点的控件**；
- 同一时刻**设置页那一行也在说话**：说明变成「DSH 正在关闭…」、按钮文案变成「正在关闭...」——两处反馈一致，而且模态（portal 到 body）稳稳盖在设置面板之上（这次没有再被面板挡住）；
- 截图里「运行状态」显示版本 `0.2.1-alpha.1-v1.1.1`，说明验的确实是这一版；
- 约 **1 秒**后进程自己退出，**启动它的作业收到退出码 0**（干净退出）。

⇒ v1.1.0 那个「点了没反应」的缺陷修复**得到真机确认**，「正在关闭」这一态现在看得见、也截得到。

**同一张截图还顺带复验了 v1.1.0 的另一处修复**：「最近一次重启」里的日志文件名与那次重启的时刻**对得上**（重启完成 17:24:33、日志文件 `…-172427.log`），不再是「沿用进程启动时刻」的旧行为。

## 4. 仍然未验证（不要当成全部通过）

1. **「实例已关闭」那一态、以及关不掉（失败态）的呈现没有截图**；`closed` 里只有一颗「知道了」时该用哪种按钮样式（当前是 `outline`），真机没看过。
2. `closing` 期间 **Esc / 点遮罩没有反应**是刻意的（这个模态是唯一一定盖得住设置面板的反馈），真机手感未复看；若希望它能被收掉（横幅还在），一行可改。
3. 关不掉的 403 / 501 / 500 仍未端到端跑过（沿用合成响应）。
4. **v1.1.0 那份 VERIFY 第 8 节的其它未验证项照旧有效**（`--port 0`、日常 profile 未安装、限频与并发的真机样本、`ctx.logger` 落点等）。
5. 修复过程中发现 `test/host.test.mjs` **把插件版本号写死**（发 v1.1.1 时当场挂）——已改成从 `package.json` 现读。这类「版本一动就红」的断言属于流程噪音，不是回归。
